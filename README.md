## Что это

**Scaffold** — оболочка вокруг терминального AI-агента (upstream-ядро форкнуто и
поставляется отдельно), которая превращает голую модель в управляемый инструмент
инженерной команды.

**TUI-first.** `scaffold` без аргументов открывает интерактивный чат-интерфейс — это
основной режим работы, а не headless-скрипт с одноразовым промптом.

**Диагностика перед кодом.** Стратегическая роль (`prime`) сама читает код, логи и
конфигурацию проекта, прежде чем предлагать план — не делегирует диагностику вслепую
субагенту, у которого нет архитектурного контекста задачи.

**План + approval.** Перед изменением кода агент формулирует план и ждёт явного
подтверждения оператора, а не действует по первому впечатлению от формулировки задачи.

**Атомарное делегирование.** Специализированным ролям (`build`, `plan`, `review`)
уходят только полностью специфицированные задачи с чётким критерием готовности — сама
архитектура и синтез результата не делегируются.

**Верифицируемое закрытие задачи (Outcome Gate).** Задача считается закрытой только
через один из трёх честных исходов: проверено лично, передано человеку с критерием
приёмки, или заблокировано с указанием конкретной причины — «записал статус и
продолжаю» не является закрытием.

**TDD-дисциплина.** Задачи с изменением кода проходят через gate, который требует
реального прогона тестов перед завершением, а не сообщения об успехе на слово.

**Профили безопасности.** Деструктивные операции и сетевые вызовы фильтруются
настраиваемой политикой (`controlled` / `strict` / `dev` / `explorer`) — от максимально
осторожного режима для чужих репозиториев до режима активной разработки.

**Роли и скиллы вместо одного универсального промпта.** Каждая роль (`prime`, `build`,
`plan`, `review`, `compose`, …) загружает собственный system prompt под свою задачу;
скиллы — markdown-инструкции, которые агент подгружает по требованию, а не держит
целиком в контексте каждого запроса.

> [!NOTE]
> Scaffold **не публикует upstream-ядро как исходный код**. Клиент получает собранный
> бинарь и данные конфигурации (роли, скиллы, политики) — не дерево TypeScript-исходников.

## Быстрый старт

Проверенный оффлайн-путь: без `git clone`, без `GITHUB_TOKEN`, без `bun`/`node` на
машине клиента — только сам собранный артефакт.

```bash
# 1. Скачать архив со сборкой для своей платформы со страницы Releases
curl -fsSLO https://github.com/pyramidheadshark/scaffold/releases/latest/download/scaffold-linux-x64.tar.gz

# 2. Распаковать
mkdir scaffold && tar -xzf scaffold-linux-x64.tar.gz -C scaffold && cd scaffold

# 3. Установить: релиз ядра лежит в отдельном публичном репозитории, а не в этом —
#    без переменной ниже install.sh уйдёт в приватный репозиторий исходников и упадёт.
#    Скрипт скачивает ядро, ПРОВЕРЯЕТ Ed25519-подпись манифеста и SHA-256 контрольную
#    сумму бинаря ядра — проверка не отключается.
export SCAFFOLD_KERNEL_REPO=pyramidheadshark/scaffold-kernel
bash install.sh

# 4. Проверить (если ~/.local/bin ещё не в PATH — установщик подскажет команду для вашего шелла)
export PATH="$HOME/.local/bin:$PATH"
scaffold --version
scaffold doctor
```

Дальше — [полный гайд](./docs/quickstart.md) с первой командой в TUI.

> [!WARNING]
> Первый релиз включает только `linux-x64`. Остальные платформы (`linux-arm64`,
> `macos-arm64`, `windows-x64` нативно через Git Bash) собираются той же
> кросс-платформенной сборкой, что уже используется для ядра — добавляются следующим
> релизом без изменения интерфейса установщика.

### Требования

`curl`, `minisign`, `jq` — скачать и проверить подписанный релиз ядра. **Bun и node на
машине клиента не нужны** — CLI поставляется скомпилированным бинарём.

### Провайдеры моделей

Официально поддерживаются: **OpenAI Codex** (OAuth, без отдельного API-ключа — `/login`
внутри TUI), **OpenRouter**, **DS Lab**. Дополнительно реализованы, но не прогонялись
живьём до продакшен-готовности: Anthropic API и Ollama (локальные модели).

```bash
export OPENROUTER_API_KEY=sk-or-...
scaffold
```

Без ключей TUI предложит настроить провайдера в Settings при первом запуске.

## Лицензия

Исходный код upstream-ядра и внутренняя логика Scaffold остаются проприетарными —
исходники в этот репозиторий не публикуются. Условия использования **поставляемого
скомпилированного бинаря** — в [`LICENSE-BINARY.md`](./LICENSE-BINARY.md). Бинарь
построен поверх нескольких MIT-компонентов; полный список атрибуций — командой
`scaffold licenses`.
